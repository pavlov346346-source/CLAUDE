# Деньги любят

…тех, кто знает, куда они уходят. Простое и красивое приложение для записи покупок
на двоих. Ставится на экран «Домой» iPhone как обычное приложение, работает без
интернета и синхронизирует записи между двумя телефонами.

**Адрес приложения:** https://pavlov346346-source.github.io/CLAUDE/

## Что умеет

- Добавить трату за пару касаний: сумма на большой цифровой клавиатуре → категория → «Добавить».
- Список трат по дням с итогом за каждый день, листание по месяцам.
- Бюджет на месяц: сколько осталось и сколько можно тратить в день до конца месяца.
- Статистика за неделю, месяц и год: по категориям (кольцевая диаграмма), по дням и месяцам,
  кто сколько потратил, самые крупные траты, сравнение с прошлым периодом.
- Категории с одинаковым названием (например, созданные на двух телефонах) считаются одной.
- Свои категории: добавить, переименовать, сменить значок и цвет, удалить. При вводе
  траты — долгое нажатие на категорию или кнопка «Изменить» (режим правки прямо в сетке);
  также Настройки → Категории.
- Валюты: рубль, индонезийская рупия, доллар, евро, тенге, бат и другие. Для рупий
  на клавиатуре есть кнопка «000», чтобы быстро набирать 25 000 или 150 000.
- Пересчёт статистики в рубли по текущему курсу из интернета: под общей суммой видно
  «≈ … ₽», а нажатием вся статистика переключается в рубли. Курс берётся из открытых
  источников (currency-api, ExchangeRate-API, ЦБ РФ) и запоминается на телефоне,
  так что последний курс показывается и без интернета.
- Выгрузка в Excel (CSV).
- Светлая и тёмная тема (как в системе), работает офлайн.

## Как запустить (один раз)

1. **Включить GitHub Pages.** В репозитории откройте
   *Settings → Pages* → в блоке *Build and deployment* выберите
   *Source: Deploy from a branch*, *Branch: `main`*, папка *`/docs`* → *Save*.
   Через 1–2 минуты приложение откроется по адресу выше.
2. **Установить на iPhone.** Откройте адрес в Safari → кнопка «Поделиться» →
   «На экран „Домой“». Сделайте это на обоих телефонах.
3. **Подключить синхронизацию** (на первом телефоне): в приложении нажмите значок
   настроек → «Подключить синхронизацию» → «Открыть GitHub». На GitHub выберите
   *Expiration: No expiration*, проверьте галочку *gist*, нажмите *Generate token*,
   скопируйте токен и вставьте его в приложение.
4. **Второй телефон:** на первом телефоне в настройках нажмите «Скопировать токен
   для второго телефона», перешлите его себе (например, в Telegram) и вставьте на втором
   телефоне в «Подключить синхронизацию» → шаг 2.

Всё. Записи, добавленные на одном телефоне, появляются на другом в течение
~20 секунд (или сразу при открытии приложения). Проверить, что оба телефона
подключены, можно в настройках: там видно «В облаке: 2 телефона».

## Где хранятся данные

- На каждом телефоне — локально, поэтому приложение работает и без интернета.
- В вашем аккаунте GitHub — в приватном gist «Деньги любят — данные приложения…»
  (у подключённых раньше — «Траты — данные приложения…»)
  (https://gist.github.com/). Его не нужно трогать; заодно это резервная копия с историей.
- Каждый телефон пишет только в свои файлы, поэтому записи с двух телефонов
  никогда не перезатирают друг друга.
- Токен хранится только на телефонах и даёт доступ лишь к gist-заметкам.

## Для разработки

Статический сайт без сборки, всё в папке `docs/`:

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css` | разметка и стили |
| `js/app.js` | экраны и шторки интерфейса |
| `js/store.js` | локальные данные, слияние записей (last-write-wins) |
| `js/sync.js` | синхронизация через GitHub Gist API |
| `js/charts.js` | SVG-графики |
| `sw.js`, `manifest.webmanifest` | офлайн-режим и установка на экран «Домой» |

Запустить локально: `npx http-server docs`.

После изменения файлов увеличьте `VERSION` в `docs/sw.js` — тогда телефоны
подтянут новую версию при следующем запуске.
